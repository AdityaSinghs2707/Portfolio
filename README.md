## ✨ Features

| Feature | Description |
|--------|-------------|
| 🖱️ Custom Cursor | Animated green cursor with ring follow effect |
| 🎞️ Scroll Animations | Fade-up reveal on scroll using IntersectionObserver |
| 📱 Responsive | Works on mobile and desktop |
| 🌑 Dark Theme | Minimal dark design with grid background |
| ⚡ Fast | Pure HTML/CSS/JS — zero dependencies |
